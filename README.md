# 🕹️ Neon Tetris (클래식 싱글 플레이어 테트리스)

로그인이나 추가 설치 없이 브라우저에서 바로 즐길 수 있는 고품질 클래식 테트리스 웹 게임입니다.  
사이버펑크 네온 비주얼, Web Audio 기반 신시사이저 사운드, 모바일 터치 패드를 지원합니다.

🌐 **실시간 웹 플레이**: [https://tommykim.github.io/tetris/](https://tommykim.github.io/tetris/)

---

## ✨ 주요 기능

- **즉시 플레이 (Zero Friction)**: 별도 회원가입이나 로그인 없이 접속 즉시 플레이 가능
- **현대적인 네온 UI**: 글래스모피즘과 사이버펑크 네온 이펙트 적용
- **사운드 시스템**: Web Audio API 기반의 아케이드 SFX 및 배경음악(BGM) 내장 (음소거 및 개별 토글 지원)
- **표준 테트리스 룰셋 준수**:
  - 7개 테트로미노 (I, J, L, O, S, T, Z) 7-Bag 무작위 추출 알고리즘
  - 다음 블록(NEXT) 3개 미리보기 및 홀드(HOLD) 기능
  - SRS(Super Rotation System) 기반 벽 튕김/월킥(Wall Kick) 지원
  - 고스트 블록(Ghost Piece) 가이드라인
  - 소프트 드롭(Soft Drop) & 하드 드롭(Hard Drop)
- **로컬 스토리지 최고 기록 저장**: 브라우저 로컬 저장소(`localStorage`)에 최고 점수 자동 보관
- **반응형 & 모바일 터치 지원**: 모바일 화면을 위한 온스크린 가상 조작 버튼 제공

## 🎮 게임 조작 방법

### 키보드 조작
| 키 입력 | 기능 |
| :--- | :--- |
| **`←` / `→`** | 좌 / 우 이동 |
| **`↑`** 또는 **`X`** | 시계 방향 회전 (SRS 월킥 적용) |
| **`Z`** | 반시계 방향 회전 |
| **`↓`** | 소프트 드롭 (빠른 낙하) |
| **`Space`** | 하드 드롭 (즉시 바닥 착지) |
| **`C`** 또는 **`Shift`** | 블록 홀드 (Hold) |
| **`P`** 또는 **`Esc`** | 일시정지 / 재개 |

### 모바일 / 터치 조작
- 하단 온스크린 가상 패드를 통해 이동, 회전, 소프트 드롭, 홀드, 드롭 조작 가능

## 🚀 로컬 실행 방법

별도의 복잡한 빌드 과정 없이 정적 파일 호스팅 또는 로컬 서버로 실행할 수 있습니다.

### Node.js 내장 서버 사용 시:
```bash
node server.js
```
브라우저에서 `http://localhost:4000` 접속
